\# Garasi Aqiqah \& Catering



Website resmi Garasi Aqiqah \& Catering yang dikembangkan untuk memperbarui tampilan, meningkatkan pengalaman pengguna, serta mengoptimalkan performa dan kualitas website.



\*\*Production Website:\*\* https://garasiaqiqah.com/



\## Project Overview



Proyek ini berfokus pada pengembangan dan penyempurnaan website Garasi Aqiqah \& Catering, mulai dari perancangan UI/UX, implementasi fitur, optimasi SEO, peningkatan performa, hingga pengujian lintas perangkat dan browser.



Repository ini merupakan dokumentasi publik proyek yang berisi gambaran pengerjaan, hasil revisi, screenshot, dan laporan pengujian. Source code website tidak disertakan dalam repository ini.

\## AI \& Development Tools



| Tools | Peran dalam Proyek |

|---|---|

| ChatGPT | Perencanaan, analisis teknis, penyusunan prompt, pemecahan masalah, dokumentasi, dan evaluasi audit. |

| Claude AI | Membantu menganalisis bug dan mencari solusi permasalahan tampilan. |

| Gemini AI | Membantu pengembangan aset gambar dan riset website sebelumnya. |

| Google Stitch | Membuat sketsa desain awal UI/UX. |

| OpenCode | Membantu implementasi kode berdasarkan instruksi serta melakukan audit perubahan. |



AI digunakan sebagai alat bantu pengembangan. Arahan, keputusan implementasi, evaluasi, dan validasi tetap dilakukan oleh tim proyek.
